How sure is this?

The European model (ECMWF) run 51 times, each from a slightly different start. Where the runs stay together the forecast is solid; where they fan out, the weather is still open. The red line is the forecast shown in the app. Today and tomorrow that forecast comes from a sharper local model (Best match), so its line can sit outside these runs.
